# Как добавить тематику для «Шпиона»

Новая тематика добавляется данными и не требует изменения игровой логики.
Каталог строится только по манифесту
`public/games/spy/themes/manifest.json`.

## 1. Создайте JSON-файл

Добавьте `public/games/spy/themes/<theme-id>.json`. Имя файла и все `id`
записывайте латиницей в `kebab-case`.

```json
{
  "schemaVersion": 1,
  "id": "city-transport",
  "name": "Городской транспорт",
  "description": "Знакомые способы передвижения по городу",
  "groups": [
    {
      "id": "public-transport",
      "name": "Общественный транспорт",
      "items": ["Автобус", "Трамвай", "Метро"]
    }
  ]
}
```

Одна группа объединяет сопоставимые объекты. В режиме другого слова игра
выбирает два объекта из одной группы, поэтому полезнее добавлять группы минимум
с двумя объектами. Одиночная группа допустима, но работает только в классическом
режиме.

## 2. Соблюдайте ограничения

- не больше 20 групп и 15 объектов в каждой — максимум 300 объектов;
- `id` — до 64 символов;
- название тематики и группы — до 80 символов;
- описание — до 200 символов;
- объект — до 80 символов;
- пустые названия, `id`, объекты и неизвестные поля запрещены;
- `id` групп и названия объектов не должны повторяться;
- повторы объектов проверяются после удаления пробелов и без учёта регистра.

Не копируйте словари из коммерческих игр или других источников без разрешения.
Добавляйте только контент, права на который принадлежат вам или разрешают такое
распространение.

## 3. Зарегистрируйте файл

Добавьте одну запись в `manifest.json`:

```json
{
  "id": "city-transport",
  "file": "city-transport.json",
  "enabled": true,
  "sensitive": false
}
```

- `enabled: true` публикует тему в приложении;
- `sensitive: true` скрывает чувствительный контент по умолчанию;
- `id` в манифесте обязан совпадать с `id` внутри файла.

Не добавляйте черновики в `public`. Локальные незавершённые наборы можно хранить
в игнорируемой папке `.local-themes/`.

Для новой темы автоматически используется нейтральная иконка. Отдельная иконка
не обязательна; её можно предложить дополнительным изменением в реестре иконок.

## 4. Проверьте вклад

```bash
npm run validate:themes
npm run check
```

Первая команда читает манифест и прогоняет каждый указанный файл через тот же
runtime-валидатор, который использует игра. Вторая запускает все проверки
проекта.

В pull request кратко опишите источник набора, принцип группировки и причину для
`sensitive: true`, если этот флаг используется.
